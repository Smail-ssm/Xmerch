🎨 4-View Apparel Templates

Interactive demo of front, back, left, and right views for T-shirts and Hoodies

👕 T-Shirt Template

📁 File Location: public/assets/svg/tshirt-4view.svg
Usage: Each view is in a separate <g> group with IDs: tshirt-front, tshirt-back, tshirt-left, tshirt-right

🧥 Hoodie Template

📁 File Location: public/assets/svg/hoodie-4view.svg
Usage: Each view is in a separate <g> group with IDs: hoodie-front, hoodie-back, hoodie-left, hoodie-right

💻 How to Integrate into Your App

Copy this code into your physical.blade.php:

// Update MockupPreview templates with 4-view URLs
mockupPreview.templates = {
    'tshirt_white': {
        name: 'White T-Shirt',
        frontUrl: "{{ asset('assets/svg/tshirt-4view.svg#tshirt-front') }}",
        backUrl: "{{ asset('assets/svg/tshirt-4view.svg#tshirt-back') }}",
        leftUrl: "{{ asset('assets/svg/tshirt-4view.svg#tshirt-left') }}",
        rightUrl: "{{ asset('assets/svg/tshirt-4view.svg#tshirt-right') }}",
    },
    'hoodie_gray': {
        name: 'Gray Hoodie',
        frontUrl: "{{ asset('assets/svg/hoodie-4view.svg#hoodie-front') }}",
        backUrl: "{{ asset('assets/svg/hoodie-4view.svg#hoodie-back') }}",
        leftUrl: "{{ asset('assets/svg/hoodie-4view.svg#hoodie-left') }}",
        rightUrl: "{{ asset('assets/svg/hoodie-4view.svg#hoodie-right') }}",
    }
};
